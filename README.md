# ⚡ Power BI Assistant - Galería Épica & Modelo Multitabla

Una aplicación web interactiva en Python (Streamlit + Plotly + Pandas) que procesa planillas Excel (.xlsx) y CSV (.csv) para generar una galería completa de componentes visuales de Power BI con contexto de negocio ejecutivo, mapas geográficos reales por países/regiones y guías paso a paso con código DAX y relaciones relacionales.

## 🚀 Despliegue Online en Streamlit Community Cloud (Link Público Gratis)

Para publicar esta app online y obtener un enlace accesible desde cualquier lugar:

1. Subir este repositorio a GitHub en `angeltapiabecerra2025/PowerB`.
2. Ir a [share.streamlit.io](https://share.streamlit.io/).
3. Iniciar sesión con tu cuenta de GitHub.
4. Presionar **"New App"**.
5. Seleccionar:
   - **Repository**: `angeltapiabecerra2025/PowerB`
   - **Branch**: `main` (o `master`)
   - **Main file path**: `app.py`
6. Hacer clic en **Deploy!**

¡Obtendrás un enlace público activo 24/7 (ejemplo: `https://powerb.streamlit.app`) para compartir con cualquier persona!
